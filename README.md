# golang-guide
Basic Go scripts to mini projects - fundementals to practical use cases

# Installing go
https://go.dev/dl/
## Linux
```
wget https://go.dev/dl/go1.25.2.linux-amd64.tar.gz
sudo tar -C /usr/local/ -xzf go1.25.2.linux-amd64.tar.gz
echo 'export PATH=$PATH:/usr/local/go/bin' >> ~/.bashrc
source ~/.bashrc
```

## Verifying
go version
